ProjectAce — Future Plan

POC is live in p1/ (Flask + SQLite + static UI). This document lists what exists today and what remains for a full production implementation.

POC shipped Full plan — not started

What the POC includes today

Run: python run.py → http://localhost:5001 · Manual: /docs/manual

Stack

  • Python 3.10+, Flask, Flask-SQLAlchemy, Flask-JWT-Extended, SQLite
  • Single-page UI in static/ (HTML + CSS + vanilla JS)
  • Seed users, projects, tasks; pytest smoke tests

Features implemented

  • Auth: JWT login; roles Admin, Manager, Employee
  • RBAC: Project-scoped access; employees move only assigned tasks
  • Projects: List, create (API), open board from table
  • Kanban: To Do / In Progress / Done; drag-and-drop with optimistic UI
  • Tasks: Add task on board; move via PATCH /tasks/:id/move
  • Dashboard: Stat cards + canvas bar charts (status, priority)
  • Employees: List (Admin)
  • Activity log: Recent entries
  • Notifications: API + DB on assign (no inbox UI)

Full implementation — still to do

Original vision: production SaaS with React + Tailwind, Node.js + Express, PostgreSQL + Prisma, Docker Compose.

1. Platform & architecture

  • Split client/ (Vite + React + React Router) and server/ (Express)
  • PostgreSQL with Prisma migrations and enums
  • Docker Compose for local Postgres (+ optional Redis)
  • Environment-based config, structured logging, health checks

2. Auth & security

  • Refresh tokens, secure cookie options, password reset flow
  • Rate limiting on login; audit all permission denials
  • Protected React routes with role-based redirects

3. Projects & tasks (product completeness)

  • Full project CRUD UI (edit, archive, deadlines, manager assignment)
  • Project membership UI; invite/remove members
  • Task detail slide-over/modal (edit title, description, priority, assignee, deadline)
  • Reorder tasks within column; persist position on server
  • Filters and search on task list

4. Kanban & real-time

  • @dnd-kit (or equivalent) in React with accessible drag-and-drop
  • Socket.io rooms per project: task:moved, task:updated
  • Optimistic UI with rollback on API failure (POC has basic version in static JS)

5. Dashboard & reporting

  • Chart.js (or react-chartjs-2) for status/priority/overdue trends
  • Manager-scoped vs org-wide dashboard views
  • PDF project report export (server-side pdfkit)

6. Notifications & activity

  • In-app notification bell with unread count
  • Deadline reminder cron (e.g. 48h before due)
  • Rich activity log (actor, action, entity link, filters)

7. UX polish

  • Loading skeletons, empty states, toast errors
  • Responsive sidebar layout; professional SaaS visual design
  • Expanded user manual aligned with production UI

8. Quality

  • Broader API integration tests; E2E (Playwright) for Kanban and RBAC
  • CI pipeline (lint, test, build)
