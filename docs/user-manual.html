ProjectAce — User Manual (POC)

Lightweight SaaS project management: projects, Kanban tasks, dashboard, role-based access.

1. Getting started

  1. Start the server (see README in p1/).
  2. Open http://localhost:5001
  3. Sign in with a demo account below.

2. Demo accounts

3. Roles

  • Admin — Full access: all projects, employees list, activity log.
  • Manager — Own projects, create tasks, move any task on the board.
  • Employee — View member projects; drag only assigned tasks on Kanban.

4. Screens

Dashboard

Stat cards (projects, tasks, completed, overdue) and bar charts for status and priority.

Projects

List of projects you can access. Click Board to open Kanban.

Kanban board

Three columns: To Do, In Progress, Done. Drag cards between columns to update status. Managers/Admins can add tasks.

Employees (Admin only)

View team members and departments.

Activity

Recent system actions (create project, move task, etc.).

5. Testing checklist

  1. Login as Admin → dashboard shows numbers.
  2. Open Kanban → drag a task to another column → refresh: status persists.
  3. Login as Employee → try moving someone else's task (should fail via API).
  4. Run automated tests: pytest tests/ from p1/ with venv active.

6. Install & run (summary)

cd p1
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python run.py
